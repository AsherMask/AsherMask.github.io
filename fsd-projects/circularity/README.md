# Circularity

A motion poem built with animated circles, random velocities, and color that drift across the screen like a living abstract scene.

## Overview

This project uses JavaScript and canvas-style drawing to generate a field of circles that move and bounce around the page. The result is a colorful visual experience that changes every time the project runs.

## Features

- Randomly generated circles
- Motion and bouncing behaviors
- Colorful visual patterns and movement
- Reusable drawing logic for creating many circle objects

## How to Run

1. Open the project folder in VS Code.
2. Open `fsd-projects/circularity/index.html` in a browser or with Live Server.
3. Refresh the page to watch the composition animate.

## Visual Notes

- Each circle is created with motion and color variation.
- The animation loops across the screen, creating a dynamic abstract effect.

## Project Files

- `index.html` — page entry for the animation
- `js/init.js` — main animation setup and logic
- `js/*.js` — supporting game and drawing modules
- `README.md` — project overview and notes
