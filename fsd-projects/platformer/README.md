# Platformer

A compact platformer project where the player navigates a level, collects items, and avoids hazards while jumping across platforms.

## Overview

This project introduces the basics of game design and JavaScript function calls. You create platforms, collectibles, and cannons to build a playable level with a clear goal.

## Features

- Custom platform layout
- Collectible objects to gather
- Cannon obstacles to avoid or time correctly
- Grid-based level design for easier placement

## How to Run

1. Open the project folder in VS Code.
2. Open `fsd-projects/platformer/index.html` in a browser or with Live Server.
3. Use the browser to play and test your level.

## Controls

- Use the platformer controls built into the game to move and jump.
- Adjust platform, collectible, and cannon positions to refine the level.

## Project Files

- `index.html` — page structure for the game
- `platformer.js` — gameplay logic and level setup
- `platformer.css` — styling for the game screen
- `setup.js` — helper setup and configuration
- `README.md` — project overview and notes
